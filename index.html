Instale antes de usar

No iPhone, o Safari apaga os dados de site que fica só em aba. Enquanto o Lembra não estiver na Tela de Início, ele vai esquecer tudo.

  1. Toque no botão Compartilhar, o quadradinho com a seta para cima, embaixo na barra do Safari.
  2. Role e escolha Adicionar à Tela de Início.
  3. Confirme e feche o Safari.
  4. Abra pelo ícone azul na tela do celular. Só por ele, daqui em diante.

Atenção: o app aberto pelo ícone começa vazio — o iPhone guarda separado do Safari. Se você já tem uma cópia salva, use Ajustes → Restaurar cópia lá dentro.

Nenhum contato guardado

Se você já tinha contatos aqui, eles foram apagados pelo navegador. Vá em Ajustes → Diagnóstico para entender, e em Restaurar cópia para trazer de volta.

Sua conta

Cole os dois valores do painel da Supabase, em Project Settings → API. A chave anon public pode ficar guardada aqui: sozinha ela não abre nada, quem protege é a regra do banco.

Diagnóstico

Se o contador de aberturas não subir depois de você fechar e abrir o navegador, é o navegador que está apagando os dados — e aí o problema não é o app. Os casos comuns são a aba anônima e a opção "limpar dados ao sair". Instalar na tela inicial também ajuda.

Cópia de segurança

Tudo fica guardado neste aparelho, e em nenhum outro lugar. Some se você limpar os dados do navegador ou trocar de celular — por isso a cópia. Mande para o seu e-mail ou para o Drive e ela sobrevive a tudo.

A cada 7 dias, se tiver acontecido coisa nova, o app cobra a cópia na tela de Discar. Copiou e não trabalhou? Ele fica quieto.

Se já houver contatos aqui, ele pergunta se é para juntar ou substituir. Juntar não perde nada dos dois lados — o histórico só é acrescentado, então dá para unir dois aparelhos sem escolher um vencedor. Arquivo com só alguns contatos sempre junta.

Zona de risco

Lembra · os dados nunca saem deste aparelho.
